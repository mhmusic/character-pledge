# The Character Pledge

A one-page pledge for creators: who you are, what you make, and how you're known — kept in your own hands and shared the way you choose.

Stewarded by Mark Haffner, adjunct professor, Volunteer State Community College.

## Hosting

`index.html` is the whole site. It is plain HTML, CSS, and a little JavaScript. No build step.

GitHub Pages: Settings → Pages → Source: Deploy from a branch → `main` / root.

## Signatures

GitHub Pages is static and cannot store anything, so the form posts to an outside service.

1. Make a free form at [Tally](https://tally.so) or [Formspree](https://formspree.io).
2. Open `index.html`, find `var ENDPOINT = "";` near the bottom, and paste the endpoint URL between the quotes.

Until then, the form tells signers to email instead.
